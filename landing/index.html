The workflow

From request to dashboard, one path.

Every spec and output follows the same non-negotiables, so quality is built in — not bolted on.

01 / INPUTS

Domain & intent

Domain, KPIs, cadence, and audience. What decision does this dashboard support?

02 / SKILL

Generate a spec

Pick a skill (daily pulse, weekly review, drilldown, alerts…). Get a structured spec: modules, data, interaction, trust, states, events.

03 / OUTPUT

Build & critique

Build the dashboard, or run the CSV pipeline for a self-contained HTML build. Review it with the critique skill.

What's inside

A library and a pipeline, ready to fork.

Everything is markdown, HTML, and a little Python — portable, diffable, and AI-friendly.

Spec-skills library

Skills that turn a request into a structured spec: exec dashboards (daily/weekly/monthly), drilldown, alerts, metric provenance, and consulting storytelling.

Templates

Document skeletons whose headings match every skill output. Copy one and fill it in.

Expert demos

Self-contained HTML demos in the voice of Tufte, Shneiderman, Ben Fry, Munzner, Few, Minto, and Knaflic.

HTML examples

Ready-to-open dashboard examples — Tailwind via CDN, shadcn-inspired styling, no build step.

CSV → dashboard pipeline

Point datasets/dashboard.yaml at your CSVs and run pipeline/run.py — profile, spec, and self-contained HTML out the other side.

Principle references

Concise summaries of the canon so any spec can cite its reasoning — clarity, integrity, and task-fit by default.

Insights & decisions

The payoff isn't more reports.

It's decision-grade views you open when you're about to act — ranked findings, honest provenance, and a narrative that leads with the answer. Here's a live one:

  • Highest-signal findings — ranked, annotated takeaways, not a wall of charts
  • Overview → drilldown — zoom and details on demand, Shneiderman-style
  • Exec narrative — a slide outline and a companion one-pager that lead with the answer
  • Alerts & exceptions — what needs attention now, surfaced first
  • Metric provenance — definitions, lineage, freshness, and caveats you can trust
  • Critique scorecard — a multi-lens review with severity-ranked findings

TufteClarity and integrity; signal over noise; no chartjunk.

Ben FryAcquire → Parse → Filter → Mine → Represent → Refine → Interact.
