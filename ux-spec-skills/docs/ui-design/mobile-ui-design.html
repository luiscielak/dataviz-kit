Executive dashboards

Daily exec pulse

Morning pulse for ops leaders scanning overnight change.

skills/10-exec-dashboards/daily-exec-pulse.skill.md

sample HTML

Purpose

Give a fast overnight read on a small KPI set—what moved, what needs attention.

When to use

Daily ops standups · overnight incident review · exec morning scan.

Inputs

  • Metrics list with owners
  • Prior-day deltas
  • Severity thresholds

Prompt

You are producing a Daily Exec Pulse…
Keep it scannable. Flag only material moves.

Output

Short pulse doc: headline · KPI strip · exceptions · next checks.

Anti-patterns

Strategy essays, 20+ KPIs, decorative charts without deltas.
