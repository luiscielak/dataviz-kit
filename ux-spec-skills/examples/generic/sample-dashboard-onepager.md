# Sample: Dashboard one-pager — Weekly performance review

**Cadence**: Weekly  
**Audience**: COO, Operations leads  
**Last updated**: 2025-02-03  

---

## Title & cadence

**Dashboard**: Weekly Performance Review (Operations)  
**Cadence**: Weekly (Monday 08:00)  

---

## Purpose

- Explain weekly performance (orders, fulfillment, returns) and variance vs plan and prior week.
- Spot which segments or regions need follow-up.
- Support Monday leadership sync with one screen and optional drilldown.

---

## How to read

- **Overview first**: Top section shows the week’s key numbers and direction (up/down vs prior week and plan). Use the variance table to see which metrics are off.
- **Then zoom / filter**: Change the week or filter by region if you need to compare or focus.
- **Then details on demand**: Click a region or segment to see order-level or DC-level detail; use the definition link for exact metric meanings and freshness.

---

## Modules at a glance

| Module | Purpose | Key metric(s) |
|--------|---------|---------------|
| Week summary | One-number pulse | Orders, Fulfillment rate, Returns; WoW % and vs plan |
| Variance table | Explain the gap | Metric, This week, Prior week, Plan, WoW %, Vs plan |
| 7-week trend | Context | Orders, Fulfillment rate, Returns over last 7 weeks |
| Segment breakdown | Where to look | Region × Orders, Fulfillment, Returns (sort by WoW or vs plan) |
| Detail (on demand) | Drill | Orders list or region detail on click |

---

## Takeaways

1. **Orders and fulfillment** — Check week summary first; use WoW % and vs plan to see if the week is on track.
2. **Variance** — Use the variance table to see which metric is driving the gap (orders, fulfillment, or returns).
3. **Segments** — Use segment breakdown to see which region or segment to focus on; click through for detail.
4. **Trend** — Use the 7-week chart to separate one-off noise from real trend.
5. **Definitions** — “Fulfillment rate” = % shipped by promised date; “Week” = Mon–Sun. Full definitions and freshness in the dashboard (link).

---

## Definitions & freshness

- **Definitions**: Orders = customer-facing order count; Fulfillment rate = % shipped by promised date; Returns = units returned in the week. Full list: [link to metric provenance].
- **Freshness**: Data as of Monday 08:00 for the week ending prior Sunday. Partial week (current week) is not used in “This week.”
