# Minto — Pyramid principle and answer-first communication

**Source**: Barbara Minto, *The Pyramid Principle*.

---

## Core ideas

- **Answer first**: Lead with the conclusion or recommendation; then support with evidence. Executives and busy readers need the “so what” before the “because.”
- **Pyramid structure**: Top = main message; below = grouped arguments; below that = supporting data. Each level summarizes the level below.
- **MECE**: Mutually Exclusive, Collectively Exhaustive—groupings should not overlap and should cover the topic.
- **Logical order**: Deductive (general → specific) or inductive (specific → general); choose consciously for the audience.

---

## For specs and storytelling

- Executive slide outlines and one-pagers: put the key message or ask on the first slide or at the top; use following slides/sections as support.
- Dashboard “purpose & decisions supported” should state the answer the dashboard enables (e.g. “Are we on plan?”) before listing modules.
- In consulting outputs (slide outline, one-pager), structure narrative as: situation → evidence → conclusion → ask; avoid evidence-first with no conclusion.

---

## Quick checklist

- [ ] Key message or ask is stated first (or on slide 1).
- [ ] Evidence supports the message; grouping is clear and non-overlapping.
- [ ] Narrative order is explicit (e.g. situation → evidence → conclusion → ask).
